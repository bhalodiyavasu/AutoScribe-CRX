# <img src="https://api.iconify.design/lucide/zap.svg?color=%2322c55e" width="28" height="28" style="vertical-align: middle;"> AutoScribe

### AI-Powered Form Filler Chrome Extension

Auto-fill any web form with realistic Indian data — using AI or instant local generation.

---

## <img src="https://api.iconify.design/lucide/sparkles.svg?color=%2322c55e" width="20" height="20" style="vertical-align: middle;"> Features

- <img src="https://api.iconify.design/lucide/brain.svg?color=%2322c55e" width="16" height="16" style="vertical-align: middle;"> **AI Smart Fill** — Context-aware form filling powered by Gemini / OpenRouter
- <img src="https://api.iconify.design/lucide/zap.svg?color=%2322c55e" width="16" height="16" style="vertical-align: middle;"> **Quick Auto Fill** — Instant offline fill with 200+ Indian names, 100+ cities
- <img src="https://api.iconify.design/lucide/layers.svg?color=%2322c55e" width="16" height="16" style="vertical-align: middle;"> **Multi-Tab Support** — Fills across tabbed forms automatically
- <img src="https://api.iconify.design/lucide/atom.svg?color=%2322c55e" width="16" height="16" style="vertical-align: middle;"> **React Compatible** — Works with React, Radix UI, and react-hook-form
- <img src="https://api.iconify.design/lucide/palette.svg?color=%2322c55e" width="16" height="16" style="vertical-align: middle;"> **Minimal Dark UI** — Draggable floating panel with live feedback
- <img src="https://api.iconify.design/lucide/settings.svg?color=%2322c55e" width="16" height="16" style="vertical-align: middle;"> **Custom API Settings** — Configure Gemini/OpenRouter API keys, toggle providers, and select LLM models dynamically

## <img src="https://api.iconify.design/lucide/download.svg?color=%2322c55e" width="20" height="20" style="vertical-align: middle;"> Installation

1. **Download the project**:
   - Click the **`<> Code`** button at the top of this repository.
   - Click **`Download ZIP`** and extract the ZIP file on your computer.

2. Open **`chrome://extensions/`** in your browser

3. Enable **Developer Mode** (top-right toggle)

4. Click **Load unpacked** → select the `AutoScribe - CRX` folder

5. **Pin** the extension to your toolbar:
   - Click the **puzzle icon** <img src="https://api.iconify.design/material-symbols/extension.svg?color=%2322c55e" width="16" height="16" style="vertical-align: middle;"> in the top-right corner of Chrome's toolbar.
   - Find <img src="icons/icon.png" width="16" height="16" style="vertical-align: middle;"> **AutoScribe** in the dropdown list.
   - Click the **pin** <img src="https://api.iconify.design/lucide/pin.svg?color=%2322c55e" width="16" height="16" style="vertical-align: middle;"> icon next to it to keep it always visible in the toolbar.

6. Navigate to any form page and **click the pinned AutoScribe icon** <img src="icons/icon.png" width="16" height="16" style="vertical-align: middle;"> to start filling!

## <img src="https://api.iconify.design/lucide/gamepad-2.svg?color=%2322c55e" width="20" height="20" style="vertical-align: middle;"> Usage

| Action | What it does |
|--------|-------------|
| Click **AI Smart Fill** | Fills form using AI-generated Indian data (needs internet) |
| Click **Quick Auto Fill** | Fills form instantly with local random data (works offline) |
| Click <img src="https://api.iconify.design/lucide/settings.svg?color=%2322c55e" width="16" height="16" style="vertical-align: middle;"> | Configure API keys, toggle AI providers, select models, and manage multi-tab fill |
| Drag <img src="https://api.iconify.design/lucide/grip-vertical.svg?color=%2322c55e" width="16" height="16" style="vertical-align: middle;"> | Move the panel anywhere on screen |
| Click <img src="https://api.iconify.design/lucide/x.svg?color=%2322c55e" width="16" height="16" style="vertical-align: middle;"> | Close the panel |
