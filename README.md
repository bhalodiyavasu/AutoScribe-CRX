# <img src="https://api.iconify.design/lucide/zap.svg?color=%2322c55e" width="28" height="28" style="vertical-align: middle;"> AutoScribe

### AI-Powered Form Filler Chrome Extension

Auto-fill any web form with realistic Indian data — using AI or instant local generation.

---

- <img src="https://api.iconify.design/lucide/zap.svg?color=%2322c55e" width="16" height="16" style="vertical-align: middle;"> **Quick Auto Fill** — Instant offline fill with 200+ Indian names, 100+ cities

## <img src="https://api.iconify.design/lucide/download.svg?color=%2322c55e" width="20" height="20" style="vertical-align: middle;"> Installation

1. **Download** or clone this repository

   ```bash
   git clone https://github.com/bhalodiyavasu/AutoScribe-CRX.git
   ```

2. Open **`chrome://extensions/`** in your browser

3. Enable **Developer Mode** (top-right toggle)

4. Click **Load unpacked** → select the `AutoScribe - CRX` folder

5. **Pin** the extension from the toolbar puzzle icon (<img src="https://api.iconify.design/lucide/puzzle.svg?color=%2322c55e" width="16" height="16" style="vertical-align: middle;">)

6. Navigate to any form page and **click the icon** to start filling!

## <img src="https://api.iconify.design/lucide/gamepad-2.svg?color=%2322c55e" width="20" height="20" style="vertical-align: middle;"> Usage

| Action | What it does |
|--------|-------------|
| Click **AI Smart Fill** | Fills form using AI-generated Indian data (needs internet) |
| Click **Quick Auto Fill** | Fills form instantly with local random data (works offline) |
| Click <img src="https://api.iconify.design/lucide/settings.svg?color=%2322c55e" width="16" height="16" style="vertical-align: middle;"> | Toggle multi-tab fill and switch AI provider |
| Drag <img src="https://api.iconify.design/lucide/grip-vertical.svg?color=%2322c55e" width="16" height="16" style="vertical-align: middle;"> | Move the panel anywhere on screen |
| Click <img src="https://api.iconify.design/lucide/x.svg?color=%2322c55e" width="16" height="16" style="vertical-align: middle;"> | Close the panel |
